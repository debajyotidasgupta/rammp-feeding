# kortex_api is NOT on PyPI -- it is published only on Kinova's Artifactory,
# so it is pinned here by direct URL.
#
# Version choice matters. 2.8.0 is the last line that still ships TCPTransport,
# which is what this arm's firmware speaks on :10000. The 3.x line dropped TCP
# for MQTT and will not connect to it. 2.6.0 also has TCP but pins
# protobuf==3.5.1, which has no wheel for Python >= 3.9; 2.8.0 allows <=3.20,
# which does. Do not "upgrade" this without re-running the connection check.
kortex_api @ https://artifactory.kinovaapps.com/artifactory/generic-public/kortex/API/2.8.0/kortex_api-2.8.0.post5-py3-none-any.whl
protobuf<=3.20
